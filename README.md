**Python • Scrapy • Google Translate API • Microsoft TTS • FFmpeg • Cron**

An automated pipeline that extracts news articles from the Press Information Bureau and generates regional-language narrated videos.

### Pipeline

```text
PIB Articles
     ↓
Scrapy
     ↓
Article Extraction
     ↓
Google Translate API
     ↓
8 Indian Regional Languages
     ↓
Microsoft Text-to-Speech
     ↓
Narrated Audio
     ↓
FFmpeg
     ↓
Regional News Videos
     ↓
Cron Automation
